# ae3.dev.tgt.xml

Development fixtures for exercising AE3's skin and XML-target rendering during framework work — not a deployable package. `devel/skin/` holds test skin packages (`skin-standard-html`, `skin-standard-xml`); `devel/test/` holds numbered example XML documents (order flows, menus, cluster status views, product/CPE views); `devel/other/` has a standalone `root-menu-source.html`.
